# Credit Default Prediction using ANN

## 📌 Overview
This project predicts whether a customer will default on credit card payments using Artificial Neural Networks.

## 📊 Dataset
UCI Credit Card Default Dataset

## ⚙️ Techniques Used
- Data Cleaning
- Feature Scaling
- SMOTE (Handling Imbalance)
- ANN (TensorFlow/Keras)

## 📈 Model Performance
- Accuracy: 82%
- ROC-AUC: 0.87

## 💼 Business Impact
- Helps banks reduce NPAs
- Improves credit risk assessment
- Enables better lending decisions

## 🛠️ Tools Used
- Python
- Pandas
- Scikit-learn
- TensorFlow
